## Featured project

### ⚡ [Dynamic Resilient Grid (DRG)](https://github.com/Tejasvi-Ponugoti/DRG_project)

An AI-enabled system for forecasting local electricity demand and analysing electrification stress in UK urban networks.

- Processed and modelled half-hourly smart-meter demand data
- Engineered calendar, lag and rolling-window features
- Compared Linear Regression with XGBoost
- Achieved **MAE 5.708 kWh**, **RMSE 7.633 kWh** and **R² 0.9912** on held-out test data
- Simulated electric-vehicle and heat-pump load scenarios
- Developed an interactive Streamlit decision-support dashboard
- Used feature importance and SHAP analysis to support model interpretation

**Technology:** Python · Pandas · NumPy · scikit-learn · XGBoost · Plotly · Streamlit · Jupyter
